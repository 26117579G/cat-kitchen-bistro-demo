# Cat Kitchen Bistro · Healthy Demo

这是一个适合课程演示的轻量级网页交互原型，不依赖 Unity、UE 或后端。四个页面已经接入独立的 16:9 AIGC 场景美术，同时保留网页原生的按钮、进度条与升级交互。

## 运行方式

直接双击 `index.html`，或在本目录启动任意静态服务器后打开它。

## 演示路径

1. 接单页点击“开始准备”。
2. 选中至少 4 种食材，点击“开始烹饪”。
3. 连续点击“开始翻炒”，展示 0% → 100% 进度。
4. 进入厨房升级，点击升级卡演示金币消耗和解锁状态。

## 两到三天制作建议

- 第 1 天：确定 4 个界面、颜色和交互流程；替换/补充 AIGC 图片资源。
- 第 2 天：完成页面布局、按钮状态和演示路径。
- 第 3 天：做用户测试、修正文字和录制 60–90 秒演示视频。

后续如果需要，可以把每个 `.screen` 拆成 Unity Canvas 或小程序页面；当前版本已经把功能状态和界面结构分开，迁移成本较低。
